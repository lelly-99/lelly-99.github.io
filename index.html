I have experience working with modern JavaScript technologies such as React for the frontend and Express.js, PostgreSQL, and MongoDB for the backend, allowing me to build scalable and efficient solutions. Whether it's implementing intuitive UI components or optimizing server-side performance, I focus on writing clean, maintainable code that’s easy to scale.

After completing my degree, I realized my passion for technology and began exploring software development.
